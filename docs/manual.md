# 使用说明（玩家向）

> 面向「装上就想用」的说明。开发相关的内容看根目录 `README.md`，
> 打包/发布看 `docs/release.md` 和 `docs/distribution.md`。

---

## 1. 她是什么

一个贴在桌面上的 3D 虚拟歌手：能跟着你的歌跳舞、唱和声、跟你一起唱，你唱得准她会高兴。

- 透明置顶窗口，**不挡你点东西**：默认鼠标穿透，只有在指针压到她身上时才接收点击
- 唱的是**你自己导入的曲目**（软件不自带任何有版权的歌）
- 支持中文 / 日本語 / English（右键菜单 → 语言）

## 2. 安装与第一次打开

| 方式 | 说明 |
|---|---|
| **安装包**（推荐） | 双击 `伴唱桌宠 Setup 0.0.1.exe`，可改安装目录，会建桌面/开始菜单快捷方式 |
| **免安装** | 直接解压 `win-unpacked` 目录，双击里面的 `伴唱桌宠.exe` |

第一次打开**只会看到她本人**，没有任何面板。想看状态和控件，**按 `H`**。

> 安装包没有代码签名证书，Windows 可能提示「未知发布者」。点「更多信息 → 仍要运行」即可，
> 这是没买签名证书的正常现象，不是文件损坏。

## 3. 三个鼠标动作

| 操作 | 效果 |
|---|---|
| 按住她拖 | 移动窗口（位置会记住） |
| 右键她 | 打开菜单：动作 / 镜头 / 语言 / 音量 / 退出 |
| 右键 → 穿透锁定 | 她完全不接收点击（干活时开着它） |

窗口大小：右键 → 尺寸（小 / 中 / 大 / 特大）。

## 4. 按键

> 记不住就按 `H`：左下角会把下面这张表铺出来（再按一次 `H` 全部收起）。

| 键 | 作用 | 键 | 作用 |
|---|---|---|---|
| `1` | 摇摆 | `2` | 挥手 |
| `3` | 转圈 | `4` | 点头 |
| `5` | 摇头 | `C` | 鼓掌 |
| `Q` | 手势（比耶等） | `N` | 拨头发 |
| `W` | 走路（她真的会走开） | `A` | 和声开关 |
| `F` | 镜头切换 / 面板 | `E` | 姿势编辑器（自用，可不管） |
| `空格` | 节拍器 | `P` | 播放 / 暂停 |
| `R` | 重来（回到开头） | `V` | 伴唱：人声开 / 关 |
| `G` | 跟唱：开 / 关麦克风 | `Y` | 人声源：原唱 ↔ 她的翻唱 |
| `L` | 穿透锁定 | `O` | 载入你自己的 `.vrm` |
| `H` | HUD + 混音条 + 键位提示 | `S` | 选曲面板 |
| `M` | 静音 | `I` | 导入歌曲 |

## 5. 面板

按 `H` 之后右上角是**混音条**，左上角是 **HUD**（诊断用，平时可以不管）：

| 面板 | 你会用到的 |
|---|---|
| 混音条 | 人声 / 伴奏 / 和声 三条滑杆；**咬字**（自动 / あ / ら / 关）；**跟唱**（开关麦克风）；**音色**（和声预设） |
| 选曲面板（`S`） | 列出已导入的曲目，点一下切歌；右侧可改名、删除（点两下才删） |
| 镜头面板（`F` 或右键「镜头 → 调整」） | 环绕角、高度、距离、注视点；三个按钮：正面 / 右上方 / 关闭 |
| HUD（`H`） | FPS、BPM、和声当前音高、麦克风电平、判定命中率等。**发给别人时不用开** |

## 6. 唱歌怎么用

1. 按 `S` 选一首歌（曲目需要先导入，见第 7 节），按 `P` 播放 —— 她会跟着跳，嘴型对齐歌词
2. 想听纯伴奏：混音条把人声拉到 0，或按 `V`
3. 想跟她一起唱：按 `G` 开麦克风（**戴耳机**，外放时麦克风会听见伴奏）
4. 想只要她唱和声：混音条把「和声」拉到 30–40%，人声拉到底
5. 她唱完会告诉你命中率，以及哪 4 秒最没跟上

**关于她的「翻唱」**（`Y`）：曲包里带 SVC 音色转换时，可以把原唱换成她的音色唱整首。
这个功能默认不带曲目，需要导入时勾选。

## 7. 做曲包（导入自己的歌）

安装包**只带播放 / 跟唱 / 和声**，做曲包要的人声分离、参考音高、逐字口型（以及给纯文本歌词
做对齐的语音识别）放在一个可选组件里（**下载 105→约 450 MB，解压后约 800 MB**，不用装 Python）：

1. 右键她 → **「做曲包组件…」**，会告诉你缺什么，并给一个「打开组件目录」按钮
2. 到 [Releases](https://github.com/aquarium-k/ai-companion-singer/releases) 下载
   `ai-companion-singer-creator-pack.zip`
3. 解压到那个组件目录（解压后应直接是 `python/`、`pylibs/`、`tools/`、`models/` 四个文件夹）
4. 按 `I` 选歌 + 歌词，导入面板会显示每一步的进度

**关于歌词**：

| 歌词 | 会走哪条路 | 时间 |
|---|---|---|
| **LRC（带时间戳）** | 直接用时间戳，不跑语音识别 | 30 秒的歌 ≈ 10–60 秒 |
| 纯文本 / 无时间戳 | 跑 Whisper 对齐（组件里的 `small` 模型） | 大约 **3–6 倍音频时长**：3 分钟的歌要 10–20 分钟，期间别关窗口 |

能拿到 LRC 就用 LRC（「自动找歌词」抓的就是 LRC）。导入完成后面板里带 `≈` 的行是插值补的，
时间不太准，可以在歌词面板里用 `K` 逐行打点修正。

导入后按 `S` 就能在选曲面板里看到她新做的曲目。

## 8. 常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 托盘里没有图标 | 系统「任务栏设置 → 哪些图标显示在任务栏上」里被关掉了；她会临时显示一个任务栏图标兜底 |
| 按 `G` 没反应 | 麦克风权限被拒；Windows 设置 → 隐私 → 麦克风，允许桌面应用 |
| 唱了但没判定 | 先看 HUD 里「跟唱」那行的输入电平；没声音就是权限或设备选错 |
| 没有声音 | 检查右键菜单的音量、混音条滑杆是否拉到 0、系统默认输出设备 |
| 她不动了 | 她自己在待机；按 `2` 挥个手，或在右键菜单里点个动作 |
| 字太小/窗口太挤 | 右键 → 尺寸换大档 |
| 按 `I` 提示「做曲包组件」 | 没装组件：按第 7 节下载解压一次即可，之后一直有效 |
| 导入卡在人声分离 | 30 秒的歌大约 10–60 秒；整首 3–5 分钟的歌要几分钟，属正常 |
| 想让她完全消失 | 右键 → 退出（托盘菜单里也有） |

## 9. 数据放在哪 / 怎么卸载

| 内容 | 位置 |
|---|---|
| 设置、曲目、日志 | `%APPDATA%\伴唱桌宠\data`、`%APPDATA%\伴唱桌宠\songpacks` |
| 安装目录 | 安装时选的位置（默认 `%LOCALAPPDATA%\Programs\伴唱桌宠`） |

卸载：设置 → 应用 → 伴唱桌宠 → 卸载（安装目录里的 `Uninstall 伴唱桌宠.exe` 也行）。
上面那两处 `%APPDATA%` 目录不会自动删，想彻底清干净就手动删掉。

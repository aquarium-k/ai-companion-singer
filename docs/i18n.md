# 多语言（i18n）

> 2026-11-18 起支持 **简体中文 / 日本語 / English** 三种界面语言。
> 这一页讲：语言怎么选、文案放在哪、加一种语言要几步、哪些还没翻。

## 一、语言怎么选

优先级（从高到低）：

1. **URL 参数** `?lang=ja`（临时看某种语言；会写进存档）
2. **存档** `pet.settings.v1` 里的 `lang`（用户上次选的）
3. **系统语言** `app.getLocale()` / `navigator.language`
4. 兜底 `zh-CN`

切换方式：

| 入口 | 说明 |
|---|---|
| 右键「语言 (Language)」 | 三个语言直接切，立即生效（原生菜单也一起切） |
| `?lang=en-US` | 命令行验证/截图用 |
| `PET_LANG=ja` 环境变量 | **只影响主进程菜单**，截图/自动化时用 |

主进程的菜单语言在启动时定一次（`app.getLocale()` + 存档），切换语言后菜单要重开右键才刷新——
这是 Electron 原生菜单的机制，不是 bug。

## 二、文案放在哪

| 位置 | 谁用 | 说明 |
|---|---|---|
| `src/i18n/zh-CN.json`、`ja.json`、`en-US.json` | 渲染层 | **一份词典一个文件**，扁平的 `key: 文案`，打 `{name}` 占位符 |
| `src/i18n/index.ts` | 渲染层 | `t(key, vars)` / `applyStaticI18n()` / `initI18n()` / `lang()` |
| `electron/i18n.cjs` | 主进程 | 只有原生右键菜单那几十条；**故意不共用**（主进程读不到打包后的 src） |

静态 HTML 文案用属性标注，不用写 JS：

```html
<span class="mix-tag" data-i18n="ui.vocal">人声</span>
<button id="att-btn" data-i18n="ui.attack.auto" data-i18n-title="ui.attack.tip">自动</button>
```

动态文案：

```ts
import { t } from './i18n'
hud.banner(t('banner.pause'), 900)
t('banner.imported', { title })          // 占位符
```

缺失的 key 会**回落中文**，再缺就返回 key 本身（所以漏翻会直接在界面上看见 `banner.xxx`）。

## 三、加一种语言（例如韩语）

1. 复制 `src/i18n/zh-CN.json` → `ko.json`，把 value 全翻掉（key 不动）；
2. `src/i18n/index.ts`：`import ko from './ko.json'`，加进 `DICTS` 和 `LANGS`，`Lang` 类型加 `'ko'`；
3. `normalizeLang()` 加一行 `if (s.startsWith('ko')) return 'ko'`；
4. `electron/i18n.cjs`：复制一个 `ko` 块（菜单文案），`SUPPORTED` 自动包含；
5. `src/main.ts` 右键「语言」子菜单里加一项 → 发 `cmd 'lang:ko'`；
6. `npx tsc --noEmit` + `node .tmp/i18n_probe.mjs ko`（换语言启动抓界面文字）验一眼。

## 四、还没翻的（已知）

| 位置 | 现状 | 为什么先不翻 |
|---|---|---|
| **HUD 逐行诊断**（`src/ui/hud.ts`） | 中文 | 它是调试/信息叠加层，字段多、句子是拼出来的；要翻得先把每行拆成 key |
| 姿势编辑器（`src/ui/poseEditor.ts`） | 中文 | 作者自己用的工具，不是玩家界面 |
| 导入面板的少量细节（`src/ui/importer.ts` 的动态行） | 中文 | 主流程（标题/按钮/空状态）已翻 |
| 各种 `console.*` 日志与错误 | 中文 | 给开发看的，不进界面 |
| 曲包格式错误信息（`src/songpack/schema.ts`） | 中文 | 面向创作者；`tools/validate_packs.mjs` 输出也一并在中文 |

用这条命令随时看还剩多少：

```powershell
python tools\list_ui_strings.py        # 按文件列出「含中文的字符串字面量」
```

## 五、翻译时注意

- **占位符别翻**：`{name}` `{style}` `{advice}` 原样保留，顺序可以调（日语常把动词放后面）。
- **不要翻 id / 命令名**：`pose.wave`、`banner.play` 这些是 key。
- 按键提示里的动作名（`keys.*`）要和右键菜单（`menu.action.*`）**用同一个词**，否则两种入口叫法不一致。
- 日语的 `一緒に歌う` 比 `跟唱` 长，按钮宽度会变——实测 `ui.mic` 三个语言都没撑破混音条；
  以后加更长的语言要顺手看一眼 `.mix-tag` 的宽度。

# 日语方向的创新点：筛选与方案

> 2026-11-15。用户问「能不能加一个关于日语的创新内容」，并要求先看别人做过什么、
> 再看我们这里有没有真原创。这份文件只记**结论 + 依据**，不写实现细节。

## 一、先说结论

**这个项目本身没有「创新」**——桌宠、VRM、lipsync、AI 翻唱都有人做过（见第二节）。
但有一件事别人没做：**从一首真实的歌里反推出「拍（モーラ）级的时间轴 + 谱面 + 发音类型」，
让同一份数据同时驱动「她的唱」和「你的评」。**

其它工具的 lipsync 是 TTS 驱动（先合成语音再对口型），卡拉 OK 採点是音高/节奏打分，
**没有一个把日语发音规则（无声音化・促音・长音・拨音）接进一个会跟你二重唱的角色**。
这就是可以主张的创新点，而且它建立在我们已经有的东西上，不是新起炉灶。

## 二、别人已经做过什么（搜过的）

| 别人做过的 | 和我们的关系 |
|---|---|
| [xiaokeai](https://github.com/liupig/xiaokeai)：开源 3D AI 伴侣 / 透明桌宠，VRM/MMD、语音、口型、动作、跳舞、多语种 | **桌宠外壳 + lipsync 已是红海**。我们唯一更深的只有「和声 + 咬字 + 翻唱」 |
| [japanese-learning-avatar](https://huggingface.co/spaces/WolfDavid/japanese-learning-avatar/blob/199a6c3e6267e359f0061e415041f650aac86dd1/src/japanese_avatar/voice/visemes.py)：VOICEVOX 的 AudioQuery → mora 口型 | 「按 mora 出口型」有先例。差别：他是 **TTS 合成**出来的 mora，我们是从**真实歌曲**里强制对齐出来的 mora 时间轴 |
| [JOYSOUND 分析採点](https://www.joysound.com/web/s/help/ranking/analysis)：音程・リズム・抑揚・安定感・表現力 | 「唱歌打分」在日语市场是成熟产品，**不能把打分当创新** |
| [こぶし 评价专利 JP2008268371A](https://patentimages.storage.googleapis.com/4f/87/b1/4b85327d044a1c/JP2008268371A.pdf) | 连「こぶし」都在採点里被判定过。所以こぶし只能算彩蛋 |
| [歌唱合成里的母音無声化 JP2010169889A](https://patents.google.com/patent/JP2010169889A/en) | 无声音化在歌唱合成里被考虑过（按假名输入就不去声化）。不在角色互动里 |
| [モーラ节奏支援（JSAI2025）](https://www.jstage.jst.go.jp/article/pjsai/JSAI2025/0/JSAI2025_3O6OS22b05/_pdf/-char/en)：听障者的歌唱节奏训练 | mora 节奏可以被单独训练/评价，说明这个切面成立，但没人做进桌宠 |

**结论**：任何单一功能都有前例；能主张的是**组合**——同一个 mora 网格同时驱动
「她的发音」和「你的发音判定」，而且她的声部是你的和声（拍必须对得上）。

## 三、我们手上已经有的（这是可行性依据）

`lyrics.units.json` 里每个 mora 都有 `t / d / ch / v`（403 个 mora，白花）。
实测：`っ` 2 个、`ん` 1 个、无声音化候选（前後都是清音的 い/う）**27 个**
（例：`さくは` `すぎて` `てきた` `した`）。所以规则不是空想，是在这首歌里能落地的。

另外：YIN 音高、逐 mora 能量、`ら/は` 起音样本库（42 段）、`あ` 的无凹陷处理、
谱面（半音锁）、`phraseGap`——「她唱」这一侧的零件都齐了。

## 四、方案（按「可听/可看 + 可量」排序）

### A. 無声化（1 天，先做这个）

日语里 `い`/`う` 夹在清音之间（或句末「です」）会**失去声带振动**：`した` 听起来像
`sh'ta`、`です` 像 `des`。现在的和声/mouth 会老老实实发一个 `i`/`u` 的元音。

- **她唱**：无声音化的 mora 不发音高元音，改成短气声（用现有的 aspirate 片段），
  音高只跟一半（气声段没有明确基频）；
- **口型**：闭口，不摆 `い/う`；
- **你唱**：谱面要求无声音化的地方，如果你唱了一个完整的元音，提示「す は無声化する」。

判据（可量）：`白花` 里 27 个候选 mora；A/B 听 `です` / `した` / `てきた` 三处；
口型上能数出「闭口帧数」多了多少。

### B. 拍の長さ（1–2 天）

`っ` = 1 拍（闭塞）、`ー` / 长音 = 1 拍（延音）、`ん` = 1 拍（鼻音）。现在这些 mora
在数据里只是 `v` 为空或 `n`。

- **她唱**：`っ` 用完整的 1 拍闭塞（现在起音片段只提前 16 ms）、`ー` 把前一个元音延长到位；
- **你唱**：拿你的起音/收音时间比谱面，报「『っ』只有 0.4 拍」「长音短了 0.3 拍」。

判据：这三类 mora 的时长和你实测的偏差；她唱那一侧听 `っ` 有没有真的憋住一拍。

### C. こぶし（彩蛋，1–2 天）

演歌/歌謡曲式装饰：句尾长音先下探再上挑。我们有谱面 + 颤音机制，加一个「演歌モード」。
**注意**：こぶし 的判定在卡啦 OK 里已有专利，所以这条只当玩法，不当创新主张。

## 五、不建议做的

- **假名注音/读音生成**：`kana.py` 已经做了，用户感知不到。
- **日语评分「唱功」**：和 JOYSOUND 正面撞，且我们只有单声道麦克风 + YIN。
- **声调（アクセント）检查**：需要 OJAD/UniDic 数据，2–3 天，而且对「唱歌」意义不大
  （旋律本来就会盖掉声调）。

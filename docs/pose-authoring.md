# 用一句话描述一个动作（姿势作者工作流）

> 2026-11-10 起。P7 姿势库 + P8 关键帧落地之后，加动作不再需要写代码，
> 而是「描述 → 拆姿势 → 量数值 → 出胶片」。
>
> **2026-11-10 追加：现在有两条路，推荐 B。**
>
> | | A. 你描述 / 给参考图 | B. 你自己摆（姿势编辑器） |
> |---|---|---|
> | 建立成本 | 0 | 0（已经做好了） |
> | 单个姿势 | 我拆 + 量 + 出图，**来回 2~3 轮**，每轮 ~30 分钟 | 你拖滑杆，**一次到位**，~5 分钟 |
> | 准确度 | 取决于我理解得对不对（唱歌姿势就偏了） | 你说了算 |
> | 适合 | 节奏、重心、整体感觉这类「说不清但看得出来」的东西 | 手放哪、肘多弯、头多歪这类精确要求 |
>
> 实际用法是**先 B 后 A**：你用编辑器摆一个准确的姿势发我，我再按 A 的方式
> 串成动作（预备拍、回落、首尾一致）。

---

## 0. 方式 B：姿势编辑器（`?editor=1`）

**打开方式（三选一）**：

1. 桌宠开着的时候按 **`Ctrl+Alt+E`**（全局快捷键，窗口没焦点也生效）——最方便
2. 点过角色让窗口拿到焦点后按 **`E`**
3. 从命令行带参数启动：`electron ... . --editor` 走不通，得用 URL 参数
   `?editor=1`（`run.bat` 里改一行，或开发时 `pnpm dev` 后手工加）

打开后窗口自动放大到 720×780，角色移到左边，右边出现面板。再按一次关掉
（窗口恢复原尺寸、角色回待机）。

1. **「从预设…」选一个最接近的姿势**（比如 `sing.ballad`、`arm.hip.L`）当起点
2. **转视角**（正脸看不出前后深度，一定要转到侧面看）：
   - 直接**用鼠标拖角色**（左右拖 = 绕角色转）
   - 或拖面板上的「视角」滑杆 / 点 `正` `侧` `背` `侧后`
   - 滚轮也能转（编辑模式下滚轮不再缩放窗口）
3. 左边点骨骼名（分组可折叠；改过的骨骼会变紫斜体）；
   **「髋位移」**是单独一项（米），下蹲、重心移动都靠它
4. 选中后拖滑杆，或者**直接在右边的输入框里敲数字**（滑杆步长 0.01，精确值靠输入）
5. 摆好按 **「复制」**，粘给我

工具条上的另外几个：

| 按钮 | 作用 |
|---|---|
| 复制 | 写系统剪贴板（走主进程），把 JSON 粘给我 |
| 粘贴 | 展开一个输入框，把我给你的 JSON 粘进去 → 应用，直接看效果 |
| 撤销 | 回退一步；`Ctrl+Z` 也行（栈 40 步） |
| 镜像 | 左右互换（`(x, -y, -z)`），左手调好可以一键变右手 |
| 清空 | 回到静息 |
| 预设 | 载入姿势库里的任意姿势当起点 |

> **剪贴板为什么不能直接调 `navigator.clipboard`**：桌面版页面是 `file://` 源，
> 属于「不安全上下文」，Chromium 会直接拒绝 `writeText`（而 `navigator.clipboard`
> 对象还在，所以很容易误以为写成功了）。现在改成 IPC 到主进程的
> `clipboard.writeText`，和页面是否聚焦、什么源都无关。
> 万一系统剪贴板也用不了，点「复制」会把 JSON 摆进输入框并全选，
> 按钮显示「手动复制」，`Ctrl+C` 即可。

**草稿会自动保存**（localStorage）：关掉编辑器、甚至重启应用，下次打开还是你上次摆到的样子。
想从干净状态开始就点「清空」或重新选预设。

⚠️ 数值是**相对静息姿态的增量**，不是绝对朝向。所以手臂「下垂」是 0，
「水平」约 1.28，「举过头顶」约 2.72。上臂三个轴：`z` 抬放、`x` 自转、`y` 前后摆。

导出的 JSON 长这样：

```json
{"leftUpperArm":[-0.2,1.1,-0.9],"leftLowerArm":[0,0,-0.15],"leftHand":[0,0,0.6],"head":[0.05,0,0.1]}
```

我拿到之后会：存成 `poses.ts` 里的一个姿势 → 按你的描述加预备拍和回落 →
出胶片给你确认 → 进动作库、绑键。

## 1. 方式 A：你描述，我试

一句话就够，比如：

> 「一手前伸、手掌向上、手自然展开，一手放在胸前、手掌与身体平行」

有用的补充（有就给，没有我自己定）：

- **哪只手**做哪个动作（默认左边前伸、右边抚胸）
- **要不要动**：只是摆着（pose），还是走一段（抬手 → 停 → 放下）
- **幅度**：温柔 / 正常 / 夸张（对应 0.7 / 1.0 / 1.3 倍）
- 参考画面（动画截图、MV 片段）也行 —— 但要接受**透视和二次元比例对不上**：
  正对镜头时纯前伸的手臂会被压成短胳膊（唱歌姿势第一版就是这么错的），
  所以截图只能定「感觉」，精确角度还是得靠 B。

## 2. 我会做什么

1. **拆成 2~4 个姿势**：起点、预备、到位、回落。写进 `src/actions/poses.ts`。
2. **量数值，不猜**：`.tmp/pose_probe2.mjs` 在页面里扫一段参数栅格、
   读手的实际世界坐标、挑最接近目标点的那组。上臂三个轴的含义已经写在
   `poses.ts` 文件头（`z` 抬放 / `x` 自转 / `y` 前后摆），但**具体角度一律量**
   —— 靠肉眼猜我错了三次（见 `choreo-plan.md` 7.6）。
3. **串成 clip**：`createKeyframeClip`，含预备拍、到位（0.1 s）、停顿、回落。
   首帧和尾帧必须是同一个姿势（代码里会 `console.warn` 检查）。
4. **出胶片给你看**：`?freeze=<clip>&t=<秒>` 逐帧截图拼成一条，
   你看完说「再来一遍 / 手再高点 / 不要这个」。
5. 你满意就进 `ACTIONS`，绑一个数字键 + 全局快捷键。

## 3. 一轮大概多久

| 动作类型 | 时间 | 说明 |
|---|---|---|
| 单个姿势（摆着不动） | ~15 分钟 | 拆姿势 + 量一次 + 一张图 |
| 一次性动作（抬手-停-放下） | ~30 分钟 | 多几个关键帧 + 一条胶片 |
| 带位移/转身/接触的动作 | 半天起 | 要等 P9 的脚部 IK，现在脚会滑 |

## 4. 姿势从哪来（2026-11-11 起）

`src/actions/userPoses.ts` 是**用户摆的姿势**，由 `.tmp/make_user_poses.py` 从
`.tmp/user_poses/incoming.json` 生成。**那个文件不要手改**——下次生成会覆盖，
而且手抄容易把左右两侧改得不一致。

流程：编辑器里摆 → 「复制」→ 发给模型 → 我把 JSON 放进 `incoming.json` → 重跑脚本。
（其实也可以直接告诉我 JSON，我替换进去，效果一样。）

`idle.base` 现在指向用户摆的 `stance`：**所有一次性动作的起点和终点都是这个站姿**，
不再是从「全零」开始的僵硬姿势。

### 只写一部分骨骼的姿势，要铺在站姿上

编辑器里的静息姿态是**手臂下垂的 rest**，不是站姿。所以作者摆「比耶」时只动了右手，
其余骨骼停在 rest；这种姿势原样当关键帧用，动作一开始双腿就会从站姿弹回笔直。
`poses.ts` 里的 `overStance()` 就是干这个的：先铺 `stance`，再盖上作者写的那几根。
第二批（转圈/摇摆/挥手/鼓掌/比耶）全部走这条路径。

## 5. 现在的边界（诚实版）

- **手能到哪儿是量出来的**：手在身前 30~40 cm 没问题；要求「手贴到脸上」
  这种接触式的，靠数值凑会差 1~2 cm，小窗里看不出来。
- **脚仍然跟着髋走**（没有 IK）：需要重心大范围移动、抬脚、转身的动作，
  脚会滑。P9 之后才能做「迈步」「踮脚转圈」。
- **手指只有「蜷 / 伸」两种程度**：VRM 每根手指三个关节，做不了很细的
  「半握」「指人时拇指压住中指」这种，但比耶、指人、张开手掌够用。
- **不做的**：大跳、下腰、翻滚（380×520 的窗口会出画）。

## 5. 例子：唱歌姿势（`pose.sing`）

**v1（我猜的，不合格）**：按「一手前伸、一手抚胸」拆成两个半身姿势，
前伸手落在 (0.32, 1.10, 0.31)、抚胸手落在 (0.08, 1.15, 0.20)。
数值是量出来的，姿势也能站住，但**和参考图不是一回事**：
手臂角度不对、抚胸手的掌心朝向也不对。

**v2（用户在编辑器里摆的，已采用）**：一次就位，数值直接存进
`src/actions/poses.ts` 的 `SING_BALLAD_BONES`，`sing.ballad` 就是它。
串成 4.3 s 的 `pose.sing`：0 → 0.6 s 抬手，停到 3.4 s，4.0 s 回到静息
（首帧和尾帧都是 `idle.base`）。胶片见 `shots/clips/strips.png` 最后一行。

**结论**：这类「像不像」的判断，我做十轮也不如你自己拖两分钟。
以后再要新动作，直接摆 + 复制 JSON 发过来，我只负责串关键帧和验收。
